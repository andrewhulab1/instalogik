L.O. – Cele lekcji / Learning objectives
  • Potrafię zamienić historyjkę na program: wczytaj – policz – wypisz.
    I can turn a story into a program: read – calculate – print.
  • Potrafię użyć kopii w drugim pudełku, gdy potrzebuję wartości dwa razy.
    I can use a copy in a second box when I need a value twice.
  • Potrafię użyć warunku (Jeżeli … skocz …) do wyboru większej liczby.
    I can use a condition (Jeżeli … skocz …) to choose the larger number.
  • Potrafię sprawdzić swój program na przykładach i na liczbach brzegowych.
    I can test my program on examples and on edge values.

Gwiazdki oznaczają trudność: ★ łatwe, ★★ średnie, ★★★ wymagają myślenia. Wyniki podawaj każdy w osobnej linii (użyj „Przejdź do nowej linii”). Zrób najpierw tabelę śledzenia na przykładach, dopiero potem pisz program.

Stars show difficulty: ★ easy, ★★ medium, ★★★ need thinking. Print each answer on its own line (use “Przejdź do nowej linii”). Make a trace table on the examples first, then write the program.

Zadanie 1: Zbieranie kasztanów ★ / Task 1: Collecting conkers

W poniedziałek Jaś zebrał n kasztanów. We wtorek zebrał tyle samo. Ile kasztanów zebrał w sumie?

On Monday Jaś collected n conkers. On Tuesday he collected the same number. How many conkers did he collect altogether?

Wejście: jedna liczba n (1–500). Wyjście: wynik w jednej linii.

Three baskets hold apples. Read the numbers of apples in the three baskets and print how many apples there are altogether.

Zadanie 5: Trzy razy tyle ★★ / Task 5: Three times as many

Read a number n and print the number 3 times as large. You have no multiplication – only addition! Think of a copy in a second box.

Zadanie 11: Kto wyższy? ★★★ / Task 11: Who is taller?

Read Jaś’s height, then Gosia’s. Print one word: JAS if Jaś is taller, GOSIA if Gosia is taller, or REMIS if they are equal.
