Język „assembly” w InstaLogik – ściągawka / The InstaLogik “assembly” language – quick reference

Program to ponumerowana lista poleceń. Komputer wykonuje je od linii 1 w dół, chyba że polecenie skoku każe iść gdzie indziej. Dane przechowujemy w czterech pudełkach: A, B, C, D. W każdym pudełku jest jedna liczba całkowita (na początku 0).

A program is a numbered list of commands. The computer runs them from line 1 downwards unless a jump sends it elsewhere. Data live in four boxes: A, B, C, D. Each box holds one whole number (it starts as 0).

Polecenie / CommandCo robi / What it does
Wczytaj do ABierze kolejną liczbę z wejścia i wkłada ją do A.
Takes the next number from the input and puts it into A.
Ustaw A na 5

Puts 5 in A (or a copy of B; B does not change).

A becomes A − 3 (or A − B). Take care not to go below 0.

Prints the number in box A.

If the condition is true go to the next line, otherwise to line 9. You can compare with a number or with another box.

Znaki porównania: = równe, ≠ różne, < mniejsze, > większe, ≤ mniejsze lub równe, ≥ większe lub równe. Warunek możesz też zapisać odwrotnie: „Jeżeli A = 5 skocz do 9 inaczej skocz do następnej”.

Comparison signs: = equal, ≠ not equal, < less than, > greater than, ≤ less than or equal, ≥ greater than or equal. You may also write the condition the other way round: “Jeżeli A = 5 skocz do 9 inaczej skocz do następnej”.

Dwa sposoby zapisu „jeśli … to … w przeciwnym razie” / Two ways to write “if … then … otherwise”

Sposób 1 – rozgałęzienie z końcem. Każda gałąź sama wypisuje wynik i kończy się „Skocz do końca”.

Way 1 – branch with an ending. Each branch prints its own result and finishes with “Skocz do końca”.

 1. Wczytaj do A
 2. Jeżeli A ≥ 10 skocz do 5 inaczej skocz do następnej
 3. Wypisz napis 'MALO'
 4. Skocz do końca
 5. Wypisz napis 'DUZO'

Sposób 2 – wartość domyślna. Najpierw ustaw wynik „na zapas”, potem popraw go, jeśli warunek tego wymaga. Wynik wypisz raz, na końcu.

Way 2 – default value. First set the result “just in case”, then correct it if the condition requires. Print once, at the end.

 1. Wczytaj do A
 2. Ustaw B na 2
 3. Jeżeli A ≥ 10 skocz do 5 inaczej skocz do następnej
 4. Ustaw B na 1
 5. Wypisz pudełko B

Oba programy rozróżniają liczby małe (< 10) i duże (≥ 10). Wybierz ten sposób, który jest dla Ciebie czytelniejszy.

Both programs tell small numbers (< 10) from large ones (≥ 10). Choose the way that is clearer to you.

Pięć kroków, zanim napiszesz pierwsze polecenie / Five steps before you write the first command

  1. Przeczytaj zadanie dwa razy i podkreśl, co wczytujesz i co masz wypisać.
    Read the task twice and underline what you read in and what you must print.
  2. Sprawdź ręcznie przykłady z treści zadania.
    Check the examples from the task by hand.
  3. Zdecyduj, które pudełko będzie na co (np. A = pierwsza liczba, B = druga, C = wynik).
    Decide which box is for what (e.g. A = first number, B = second, C = result).
  4. Napisz program i przetestuj go na papierze tabelą śledzenia – także dla liczb brzegowych (najmniejsza, największa, równe).
    Write the program and test it on paper with a trace table – including edge values (smallest, largest, equal).
  5. Sprawdź numery linii w skokach – po dopisaniu polecenia wszystkie numery za nim się przesuwają!
    Check the line numbers in jumps – after inserting a command, every number after it shifts!

Najczęstsze błędy / Most common mistakes

  • Brak „Przejdź do nowej linii” między dwiema liczbami do wypisania.
    No “Przejdź do nowej linii” between two numbers to print.
  • Pomylone znaki < i ≤ (albo > i ≥) – zawsze sprawdź liczbę równą granicy.
    Mixed-up < and ≤ (or > and ≥) – always test the number equal to the border.
  • Po jednej gałęzi program „wpada” w kod drugiej gałęzi, bo zabrakło „Skocz do końca” lub „Skocz do …”.
    After one branch the program “falls into” the other because “Skocz do …” is missing.
  • Zmiana pudełka, którego wartość jeszcze jest potrzebna (najpierw skopiuj!).
    Changing a box whose value is still needed (copy it first!).
  • Odejmowanie, które daje liczbę ujemną.
    A subtraction that gives a negative number.
