Umiesz już pisać programy w języku InstaLogik. Python działa tak samo — tylko zamiast pudełek A, B, C, D masz nazwy, które wymyślasz sam, i nie musisz skakać do numerów linii. To ta sama logika w wygodniejszym ubraniu.

You can already write programs in the InstaLogik language. Python works the same way — instead of boxes A, B, C, D you invent your own names, and you do not jump to line numbers. The same logic, more comfortable clothes.

Python uruchamia się tutaj w Twojej przeglądarce. Przy pierwszym kliknięciu „Sprawdź” strona pobiera go z internetu, co trwa kilka sekund — potem jest już szybko. Twój kod nigdzie nie jest wysyłany.

Python runs here in your own browser. The first time you click Check the page downloads it, which takes a few seconds — after that it is fast. Your code is never sent anywhere.

1. Pudełka to zmienne / Boxes are variables

InstaLogik
 1. Ustaw A na 5
 2. Zwiększ A o 3
 3. Wypisz pudełko A
Python
a = 5
a = a + 3
print(a)

Nazwa może być dowolna: a, wiek, liczba_kasztanow. Nie musisz jej wcześniej zapowiadać — wystarczy przypisać wartość.

The name can be anything. You do not declare it first — assigning a value is enough.

2. Wczytywanie liczb / Reading numbers

InstaLogik
 1. Wczytaj do A
 2. Wypisz pudełko A
Python
a = int(input())
print(a)

input() czyta jedną linię, a int(...) zamienia ją na liczbę. Bez int Python potraktowałby to jako tekst i 2 + 2 dałoby 22.

input() reads one line, int(...) turns it into a number. Without int Python would treat it as text.

Na tej stronie każda liczba wejściowa jest w osobnej linii, więc trzy liczby czytasz trzema poleceniami input().

On this page each input number is on its own line, so three numbers need three input() calls.

3. Warunki / Conditions

InstaLogik
 1. Wczytaj do A
 2. Wczytaj do B
 3. Jeżeli A > B skocz do
    następnej inaczej skocz do 6
 4. Wypisz pudełko A
 5. Skocz do końca
 6. Wypisz pudełko B
Python
a = int(input())
b = int(input())
if a > b:
    print(a)
else:
    print(b)

Zwróć uwagę na dwie rzeczy: dwukropek na końcu linii z if oraz wcięcie o cztery spacje. W Pythonie wcięcie zastępuje skoki — to ono mówi, co należy do warunku.

Note the colon and the four-space indent. In Python the indent replaces jumps — it says what belongs to the condition.

4. Pętle / Loops

InstaLogik
 1. Wczytaj do A
 2. Ustaw B na 0
 3. Jeżeli A > 0 skocz do
    następnej inaczej skocz do 7
 4. Zwiększ B o A
 5. Zmniejsz A o 1
 6. Skocz do 3
 7. Wypisz pudełko B
Python
n = int(input())
suma = 0
for i in range(1, n + 1):
    suma = suma + i
print(suma)

Tu Python naprawdę wygrywa. range(1, n + 1) daje kolejne liczby od 1 do n, a pętla for wykonuje wcięty fragment dla każdej z nich. Żadnych skoków i numerów linii.

Here Python really wins. range(1, n + 1) gives the numbers from 1 to n, and the for loop runs the indented part for each one.

5. Wypisywanie / Printing

print(a) wypisuje wartość i od razu przechodzi do nowej linii — czyli robi to, co w InstaLogiku wymagało dwóch poleceń: „Wypisz pudełko A” i „Przejdź do nowej linii”.

print(a) prints the value and moves to a new line, doing what needed two commands in InstaLogik.
